# DEV-028: Gestão de utilizadores na aplicação

Hoje não existe forma de criar utilizadores na aplicação. Só é possível pela CLI (`backend/app/cli.py`, comando `create-user`, que usa `UserService.create_user`). O README §3 e o §4.8 indicam que o Administrador gere os utilizadores.

## Âmbito

- API protegida pela permissão `USERS_MANAGE` para listar, criar e editar utilizadores (nome, email, perfil) e para os ativar ou desativar.
- Redefinição de password pelo administrador.
- Página de Administração → Utilizadores no frontend, visível só ao perfil Administrador.
- Reutilizar as validações existentes (email único, regras de password) e registar as alterações na auditoria.
- Testes de backend e frontend.

## Questões a confirmar antes de implementar

- O DEV-027 indica que a aplicação tem um único utilizador (o gestor). É preciso confirmar se o objetivo passa a ser vários utilizadores com perfis diferentes.
- Confirmar se é necessário apagar utilizadores ou se basta desativá-los (recomendado, para manter o histórico).
- Exige work-spec (`implementation-plan-v1`) porque toca em mais de 3 ficheiros.
