# DEV-029: Aspeto visual mais profissional do site

Melhorar o aspeto do frontend (React + Tailwind CSS 4, `frontend/src/index.css`) para um visual mais profissional e consistente.

## Âmbito

- Definir uma identidade visual: paleta, tipografia, espaçamentos, sombras e raios, através de tokens no tema do Tailwind.
- Reformular o layout base: barra lateral de navegação, cabeçalho, utilizador autenticado e logótipo.
- Uniformizar os componentes comuns (botões, formulários, tabelas, cartões, badges de estado e prioridade, modais, estados vazios e de carregamento).
- Melhorar o dashboard e os gráficos (Recharts) com cores coerentes com o tema.
- Garantir acessibilidade (contraste, foco visível) e um layout responsivo.
- Não alterar funcionalidades. Os testes de frontend existentes têm de continuar a passar.

## Questões a confirmar antes de implementar

- Referência visual ou estilo pretendido (ex.: Jira/Linear) e cores da marca.
- Modo escuro: incluir ou não.
- Usar uma biblioteca de componentes (ex.: shadcn/ui) ou manter componentes próprios.
- Exige work-spec (`implementation-plan-v1` e eventualmente `wireframes-v1`) porque toca em mais de 3 ficheiros.
